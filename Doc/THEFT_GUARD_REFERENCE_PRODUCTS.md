This document records commercial products that are relevant examples for the CarTheftGuard project. Listings are included for feature comparison and research; inclusion is not a purchase endorsement.

## SinoTrack ST-906L 4G GPS vehicle tracker

- Product listing: [AliExpress item 1005009640067787](https://he.aliexpress.com/item/1005009640067787.html)
- Seller/model shown: SinoTrack ST-906L
- Product category: wired 4G vehicle GPS anti-theft tracker
- Listing variants shown: `Wire Only` and `With Accessories`

### Relevant advertised features

- 4G cellular connection
- GPS vehicle location and online tracking
- SMS/GPRS tracking and alerts
- ACC/ignition status monitoring
- Movement and overspeed alerts
- External relay support for remote fuel/power circuit interruption
- Internal backup battery and external-power-loss alert

### Relevance to this project

The ST-906L is a useful market reference for the planned CarTheftGuard feature set:

- Remote vehicle location through GNSS and cellular data
- SMS as a fallback command and alert channel
- Mobile/online status monitoring
- Ignition and external-power monitoring
- Backup-power detection
- Carefully controlled immobilization output

### Safety and evaluation notes

- Do not interrupt an engine, fuel circuit, or other safety-critical circuit while a vehicle is moving.
- Remote commands should be authenticated and protected against replay; caller ID alone is not authentication.
- Verify the exact LTE bands, SIM compatibility, GNSS capability, subscription requirements, server availability, wiring diagram, and included accessories before purchase.
- The listing's advertised functionality and automatically translated text have not been independently verified.
